Getting this into UVtools

.sl1 (default): it's a real Prusa SLA archive — just File → Open it in UVtools directly, then use Tools → Edit print parameters to fine-tune exposure/lift/etc., and File → Save as to convert to your printer's native format (.ctb / .pwmx / .goo).

Plain image ZIP (fallback): unzip it, then in UVtools use File → New → From images… and select layer_0000.png, or Tools → Import Layers onto a dummy 1-layer project for your printer. Apply the numbers from settings.txt, then save.

White pixels = UV passes through = cured resist/resin. Use Invert above if your exposed-vs-masked areas come out backwards for your process.
