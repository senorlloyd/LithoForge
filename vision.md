# LithoForge Vision

LithoForge is an open-source digital lithography platform.

The project began as an educational tool to teach semiconductor
manufacturing concepts using inexpensive LCD resin printers and UV
exposure systems.

The long-term goal is to provide an open, extensible platform that
can generate exposure files for multiple printer formats while
remaining simple enough for students and educators to understand.

Core Principles

- Education comes first.
- Open source.
- Multiple printer formats.
- Clean, well-documented code.
- Modular architecture.
- Every feature should help users understand digital lithography.
